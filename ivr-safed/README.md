# שלוחת זמני ערב שבת – בית כנסת בצפת

שלוחת API בימות המשיח שמשמיעה מתי מנחה (וכולל) בערב שבת הקרוב, לפי זמן הדלקת הנרות בצפת כמו בלוח **עתים לבינה**: 30 דקות לפני השקיעה מהגובה (779 מ').

פרויקט נפרד לגמרי מ"זמני מניינים": תיקייה משלו, בלי מסד נתונים ובלי קוד משותף. כרגע הוא רץ בתוך ה-Worker של זמנים, בכתובת `smti.uk/zmanim/ivr-safed`, ואפשר להעביר אותו ל-Worker משלו (ראו למטה).

## הגדרת השלוחה (ext.ini)

```
type=api
api_link=https://smti.uk/zmanim/ivr-safed?kollel=30
api_hangup_send=yes
```

ברירת המחדל: "מנחה ערב שבת בשעה …" בזמן הדלקת הנרות. הכולל נאמר רק כשמוסיפים לו דקות בקישור.

## פרמטרים בקישור

| פרמטר | מה עושה | דוגמה |
|---|---|---|
| `kollel` | כמה דקות לפני הדלקת הנרות הכולל. `off` = לא לומר | `kollel=30` |
| `minha` | כמה דקות לפני הדלקת הנרות מנחה (ברירת מחדל 0, מספר שלילי = אחרי). `off` = לא לומר | `minha=0` |
| `items` | מחליף את כל הרשימה: `שם:דקות` מופרדים ב-`;` | `items=כולל ערב שבת:30;מנחה ערב שבת:0` |
| `candle` | הדלקת נרות כמה דקות לפני השקיעה מהגובה (ברירת מחדל 30) | `candle=30` |
| `say_candles` | `1` = לומר גם את זמן הדלקת הנרות בהתחלה | `say_candles=1` |

מחברים כמה פרמטרים עם `&`, למשל `?kollel=30&say_candles=1`.

## איך מחושב

- השקיעה מחושבת עם שניות (אלגוריתם NOAA) לפי הגובה, פחות 10 שניות תיקון כדי להתאים ללוח, פחות 30 דקות, ומעוגלת כלפי מטה לדקה כמו בלוח.
- נבדק מול עתים לבינה לשבוע 8–13.11.2026: כל הדקות תואמות (13.11: הדלקה 16:12).
- "ערב שבת הקרוב": מראשון עד שישי – השישי של השבוע; בשבת – של השבוע הבא.
- אם פעם יש הבדל מהלוח, אפשר לקבוע זמן לשבת מסוימת ב-`CANDLE_OVERRIDES` שב-`src/config.js`.

## העברה ל-Worker נפרד

1. מעבירים את התיקייה ל-repo חדש (יש בה `package.json` ו-`wrangler.toml` משלה).
2. `npx wrangler deploy` מתוך התיקייה, ומוסיפים Route, למשל `smti.uk/ivr-safed*`.
3. מוחקים מ-`api/src/index.js` של זמנים את שתי השורות של `ivrSafed`.
