# תוספת דקות

כל מתקשר מעדכן בטלפון כמה דקות להוסיף לסכום שלו, ובשלוחה אחרת אפשר רק לשמוע כמה נצבר. הכל לפי מספר הטלפון של המתקשר. יש גם ממשק ניהול משלו.

פרויקט נפרד לגמרי מזמני מניינים: תיקייה משלו, בלי קוד משותף, וטבלאות משלו שכולן מתחילות ב-`minutes_`. כרגע הוא רץ בתוך ה-Worker של זמנים:

| מה | כתובת |
|---|---|
| ממשק הניהול | `https://smti.uk/zmanim/ivr-minutes/` |
| שלוחת עדכון | `https://smti.uk/zmanim/ivr-minutes/add` |
| שלוחת שמיעת הסכום | `https://smti.uk/zmanim/ivr-minutes/total` |

## הפעלה ראשונה

1. ב-Cloudflare, ב-Worker בשם `zmanim`, נכנסים ל-Settings, ואז ל-Variables and Secrets. מוסיפים Secret בשם `MINUTES_PASSWORD` עם סיסמת הניהול.
2. נכנסים לממשק, ובלשונית **הגדרת שלוחות** בוחרים הגדרות ומעתיקים את ה-ext.ini המוכן לכל אחת משתי השלוחות בימות המשיח. הקישור כולל מפתח גישה, ובלעדיו השלוחה חסומה.

הטבלאות נוצרות לבד בפנייה הראשונה, ולא צריך להריץ מיגרציה.

## שלוחת עדכון (`/add`)

```
type=api
api_link=https://smti.uk/zmanim/ivr-minutes/add?key=<המפתח>&max=60&times=1&per=day
api_hangup_send=no
```

| פרמטר | מה עושה | ברירת מחדל |
|---|---|---|
| `max` | כמה דקות לכל היותר בעדכון אחד | 60 |
| `times` | כמה עדכונים מותרים בכל פרק זמן | 1 |
| `per` | פרק הזמן: `day` (יום לפי התאריך), `week` (משבוע ראשון), `month`, `ever` (בכל הזמן), או זמן מתגלגל: `90m`, `12h`, `3d` | `day` |
| `edit` | `no` = אי אפשר לשנות את העדכון כשהגיעו למגבלה | מותר |
| `hours` | `1` = להשמיע בשעות ודקות ("שעתיים ו 15 דקות") | דקות |
| `list` | רשימה נפרדת עם ספירה משלה (למשל `list=חנוכה`) | `main` |

מה שומע המתקשר:
- **כשמותר לעדכן:** "עד כה צברת X". אחר כך הוא מקיש כמה דקות להוסיף ואת הסולמית. ימות המשיח משמיע את המספר ומבקש אישור. אחר כך הוא שומע "הוספת Y, סך הכל צברת Z".
- **כשכבר עדכן את מספר הפעמים המותר בפרק הזמן:** "כבר עדכנת היום Y". אחר כך: "לשינוי העדכון הקישו 1". הוא מקיש את המספר המעודכן, ו-0 מבטל את העדכון. השינוי חל על העדכון האחרון שבפרק הזמן, ולא נספר כעדכון נוסף.
- יותר מ-`max`, או 0, לא מתקבל, ונשאל שוב (עד 3 פעמים).
- מספר חסוי לא יכול לעדכן.

## שלוחת שמיעת הסכום (`/total`)

```
type=api
api_link=https://smti.uk/zmanim/ivr-minutes/total?key=<המפתח>
api_hangup_send=no
```

המתקשר שומע "עד כה צברת X". אפשר להוסיף `all=1` כדי להשמיע גם את הסכום של כל המשתתפים, וגם `hours=1` ו-`list=` כמו בשלוחת העדכון.

## הממשק

- סיכום: כמה נצבר, כמה משתתפים, כמה נוסף היום.
- **משתתפים:** כל מספר עם הסכום שלו, חיפוש וייצוא ל-CSV (נפתח באקסל). לחיצה על מספר פותחת את כל העדכונים שלו. אפשר לערוך, למחוק, להוסיף ידנית (גם מספר שלילי לתיקון) ולתת לו שם לזיהוי.
- **פעילות:** יומן של כל הוספה, שינוי ומחיקה, מהטלפון ומהממשק.
- **הגדרת שלוחות:** בונה את ה-ext.ini לשתי השלוחות. כאן גם מחליפים את מפתח הגישה.
- רשימות: בוחרים או יוצרים רשימה בראש הדף. כל רשימה נפרדת לגמרי.

## איך זה בנוי

- `src/ivr.js`: שתי השלוחות. אין שמירת מצב: ימות המשיח מחזיר בכל בקשה את כל הערכים שנקלטו בשיחה, וכל שאלה מקבלת שם חדש (`a1`, `a2`, `c1`, `e<id>_1` …). שליחה חוזרת של אותה בקשה לא מוסיפה פעמיים, כי לכל שיחה (`ApiCallId`) יש לכל היותר הוספה אחת.
- `src/period.js`: פרקי הזמן לפי שעון ישראל.
- `src/admin.js`: ה-API של הממשק. הסיסמה היא הסוד `MINUTES_PASSWORD`, והטוקן חתום ל-30 יום. החלפת הסוד מנתקת את כולם. אחרי 8 ניסיונות כושלים יש חסימה לרבע שעה.
- `src/ui.js`: הממשק, קובץ HTML אחד בלי ספריות.
- `src/schema.js`: הטבלאות.

## בדיקות

```
npm test
```

וגם הרצה מקומית: `node scripts/preview.mjs` מתיקיית הפרויקט הראשי, ואז `http://localhost:8787/zmanim/ivr-minutes/` עם הסיסמה `preview`.

## העברה ל-Worker נפרד

1. יוצרים מסד D1 חדש. כרגע אי אפשר, כי בחשבון יש כבר 10 מסדים, וזו המגבלה. כותבים את ה-id שלו ב-`wrangler.toml` שבתיקייה, ומעבירים את טבלאות `minutes_*`.
2. `npx wrangler secret put MINUTES_PASSWORD` ואז `npx wrangler deploy` מתוך התיקייה, ומוסיפים Route.
3. מוחקים מ-`api/src/index.js` של זמנים את שתי השורות של `ivrMinutes`.
